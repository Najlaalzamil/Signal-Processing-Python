# Signal Processing Using Python

## Overview
This is a small independent practice project demonstrating a basic signal-processing workflow:
1. Generate a sample signal from two sine waves.
2. Add random noise to simulate a noisy measurement.
3. Apply a moving-average filter.
4. Plot the original, noisy, and filtered signals for comparison.

## Requirements
- Python 3
- NumPy
- Matplotlib

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python main.py
```

The script displays the comparison plot and saves it as `signal_processing_result.png`.

## Concepts demonstrated
- Numerical arrays with NumPy
- Signal generation
- Random noise
- Convolution and moving-average filtering
- Visualization with Matplotlib
